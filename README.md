# VYUHAK // Orbital Intelligence Protocol

**VYUHAK** (Sanskrit: *Vyūhaka* — A tactical formation, matrix, or array) is a next-generation Geospatial Open-Source Intelligence (OSINT) and Earth Observation platform. 

It provides an aerospace-grade, browser-based Mission Control interface to monitor real-time global telemetry, simulate artificial satellite constellations, and aggregate live data feeds (like USGS Seismic activity and NASA EONET thermal anomalies) mapped directly onto a 3D digital twin of the Earth.

## Features (v5.0 Prototype)
- **Cinema-Grade Aerospace UI/UX:** Obsidian sapphire glassmorphism, tabular typography (JetBrains Mono + Space Grotesk), and precision SVG reticles.
- **Interactive 3D Earth Engine:** Powered by Three.js with simulated atmospheric scattering and orbital mechanics.
- **Multi-Spectral Sensor Simulation:** UI modes for True-Color Optical, FLIR Thermal, Tactical Night Vision (NVG), and Synthetic Aperture Radar (SAR).
- **Orbital & Geostationary (GEO) Lock Modes:** Toggle satellites between Free Orbit (LEO) and Geostationary hover over specific coordinates.
- **Synthesized Tactical Audio:** Native Web Audio API engine providing zero-dependency UI feedback (clicks, orbital locks).
- **Mobile-First Unobstructed Viewport:** Bottom-dock architecture ensures the 3D globe remains the hero element on all devices.

## Quick Start
No build step required. VYUHAK is a pure front-end application.
1. Clone the repository.
2. Open `index.html` in any modern web browser.
3. Use the **Command Palette shortcut (`Cmd/Ctrl + K`)** or the UI buttons to interact.

## Tech Stack
- **HTML5 / CSS3 / Vanilla JavaScript**
- **Three.js** (WebGL 3D Rendering)
- **Tailwind CSS** (via CDN for rapid UI styling)
- **Web Audio API** (Synthesized sound engine)
