# VYUHAK v21 COSMOS PRIME // Real-Time Earth, ISS & Keplerian Solar System

VYUHAK (*Virtual Yield Uplink & Heuristic Aerospace Kinematics*) is a serverless 3D/2D orbital intelligence and heliocentric Solar System platform built with Three.js custom GLSL shaders, Leaflet.js, and 100% free, keyless live APIs.

## What's New in v21 COSMOS PRIME
- **3D Major Moons Across the Solar System:** Added mathematically orbiting natural satellites with orbital rings for Earth (Moon), Mars (Phobos, Deimos), Jupiter (Io, Europa, Ganymede, Callisto), Saturn (Enceladus, Rhea, Titan), Uranus (Titania, Oberon), and Neptune (retrograde Triton), plus true axial tilts (including Uranus's 97.77° sideways tilt) and a 1,000-body outer Kuiper Belt.
- **Full Lower-Drawer Cosmos Data Dossier:** Entering `Cosmos` mode transforms the lower slide-up drawer into a live **Cosmos Data** dossier projecting:
  1. Live Wikipedia astronomical overview for the selected body.
  2. Real-time NASA JPL J2000 Keplerian ephemeris (Sun AU, Earth distance in million km, 1-way light-time, vis-viva orbital velocity, eccentricity, inclination, and axial obliquity).
  3. Physical & atmospheric telemetry (equatorial radius, gravity, escape velocity, mean temperature, day length, and atmosphere composition).
  4. Natural satellites count & interactive moon list with orbital periods.
  5. Live **NOAA SWPC Space Weather** (real-time Solar Wind speed in km/s and Geomagnetic Kp-index).
